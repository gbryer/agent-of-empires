`container_workdir` threading approach: D-10 mandates `caps` as a parameter on the pure function (mockable, no global lookup). The 19-site count from RESEARCH overrides CONTEXT.md's ~5 estimate. The pure `container_workdir(caps)` retains the D-10 contract; the helper isolates the global lookup. Trade-off documented: one extra method, but cuts 19 mechanical edits to a uniform `_now` append. Acceptable because the helper is a 3-line wrapper with one caller pattern.

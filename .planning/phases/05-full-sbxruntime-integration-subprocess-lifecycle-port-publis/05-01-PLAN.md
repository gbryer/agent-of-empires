<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| aoe process -> sbx subprocess | Argv passed to Command::new; controlled by typed builders, not user string input |
| sbx stdout -> aoe parse | JSON from sbx ls --json parsed via serde with #[serde(default)]; malformed JSON returns Err |
| sbx stderr -> aoe logs | stderr text captured in DockerError::CommandFailed; surfaced via tracing::warn, never shown raw to end-user |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | sbx subprocess argv | mitigate | All argv built via pure typed builders (build_create_args, build_exec_args, build_ports_args); container names generated by DockerContainer::generate_name (alphanumeric + truncated UUID); no user-controlled strings interpolated into shell |
| T-05-02 | Information Disclosure | sbx stderr in error messages | mitigate | stderr captured in DockerError::CommandFailed(String); session layer logs via tracing::warn (not displayed raw to user in TUI); Phase 6 controls TUI rendering |
| T-05-03 | Information Disclosure | env vars in process argv | mitigate | EnvEntry::Inherit passes only KEY in argv (per existing pattern at runtime_base.rs); value stays in process environment, not visible in ps output |
| T-05-04 | Denial of Service | readiness probe infinite loop | mitigate | Bounded exponential backoff with 7 attempts max (~25s total); returns Err after exhaustion, never blocks indefinitely |
| T-05-05 | Spoofing | sbx ls --json output from untrusted source | accept | sbx binary is user-installed on their own machine; aoe trusts the local sbx installation (same trust model as Docker/Podman) |
</threat_model>

<objective>
Implement the post-wake clock-resync handler for sbx sandboxes, with platform-specific wake detection via IOKit on macOS and D-Bus on Linux.

Purpose: Prevents HTTPS handshake failures in sbx microVMs after macOS sleep by forcing clock interaction with the host via `sbx exec <name> date` on resume. Fire-and-forget with tracing::warn on failure.

Output: Modified `src/process/mod.rs` (public API), `src/process/macos.rs` (IOKit listener), `src/process/linux.rs` (D-Bus listener), with unit tests for the resync logic.
</objective>

No new imports needed beyond what already exists.

    Also add a `pub(crate) fn resync_sbx_clocks()` function in mod.rs (NOT platform-specific; the resync logic is identical on all platforms). This function:
    1. Runs `Command::new("sbx").args(["ls", "--json"]).output()` and parses sandbox names from the JSON (expects `{"sandboxes": [{"name": "..."}]}` shape). Uses serde_json for parsing with a local struct annotated `#[serde(default)]`. On any failure, logs `tracing::warn!(target: "process.wake", ...)` and returns early.
    2. Calls `crate::session::list_profiles()` to iterate all profiles. For each profile, calls `Storage::new(profile).load()` to get instances.
    3. Filters instances to those where: `is_sandboxed() == true`, `created_at` is older than 5 minutes (`Utc::now() - chrono::Duration::minutes(5)`), AND `sandbox_info.as_ref().unwrap().container_name` appears in the set of sbx-managed sandbox names from step 1.
    4. For each matching instance, runs `Command::new("sbx").args(["exec", &container_name, "date"]).output()` fire-and-forget. Logs `tracing::info!(target: "process.wake", sandbox = %name, "clock resync successful")` on success, `tracing::warn!(target: "process.wake", sandbox = %name, ...)` on failure.

    Import additions for mod.rs: `use std::collections::HashSet;`, and conditionally gate `use crate::session::{list_profiles, storage::Storage};` behind `#[cfg(any(target_os = "linux", target_os = "macos"))]` so it only compiles on platforms that have the wake handler. Also add `use chrono::Utc;` and `use serde::Deserialize;` (both already in Cargo.toml deps).

    **src/process/macos.rs** - Add `pub(super) fn register_wake_handler()` that spawns a `std::thread::spawn` with a blocking IOKit power notification listener. The thread:
    1. Declares `extern "C"` FFI bindings for: `IORegisterForSystemPower`, `IONotificationPortGetRunLoopSource`, `CFRunLoopGetCurrent`, `CFRunLoopAddSource`, `CFRunLoopRun`, and the `kCFRunLoopDefaultMode` extern static. Add `#[link(name = "IOKit", kind = "framework")]` on the extern block.
    2. Defines a `power_callback` extern "C" function that checks if `message_type == 0xe0000300` (kIOMessageSystemHasPoweredOn) and calls `super::resync_sbx_clocks()`.
    3. In the thread body: calls `IORegisterForSystemPower`, gets the run loop source, adds it to the current run loop, and calls `CFRunLoopRun()` (blocks forever).
    4. If registration fails (root_port == 0), logs `tracing::warn!(target: "process.wake", "Failed to register for IOKit power notifications")` and returns from the thread.

    **src/process/linux.rs** - Add `pub(super) fn register_wake_handler()` that spawns a `std::thread::spawn` with a `busctl monitor` subprocess. The thread:
    1. Spawns `Command::new("busctl").args(["monitor", "--system", "--match", "type='signal',interface='org.freedesktop.login1.Manager',member='PrepareForSleep'"])` with stdout piped and stderr null.
    2. On spawn failure, logs `tracing::warn!(target: "process.wake", "Failed to spawn busctl for wake monitoring")` and returns.
    3. Reads stdout line-by-line via BufReader. When a line contains the string "false" (indicating PrepareForSleep(false) = waking up), calls `super::resync_sbx_clocks()`.
    4. If the busctl process exits, the thread exits silently (the handler is best-effort).

    Add a unit test in src/process/mod.rs (in-module `#[cfg(test)]` block) that tests the filtering logic of resync_sbx_clocks indirectly: create a helper `fn filter_resync_candidates(instances: &[Instance], sbx_names: &HashSet<String>, threshold: DateTime<Utc>) -> Vec<String>` and test it with mock Instance data. This avoids needing a real sbx binary for the unit test.

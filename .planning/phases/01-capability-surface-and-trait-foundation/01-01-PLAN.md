<objective>
Introduce `RuntimeCapabilities` as a first-class data shape on `ContainerRuntimeInterface`, migrate the existing two flags (`supports_read_only_volumes`, `supports_remove_volumes`) into it, and add the five new flags from REQ-RT-03 (`supports_port_publish_at_create`, `supports_image_pull`, `supports_anonymous_volumes`, `supports_arbitrary_volume_paths`, `supports_dynamic_port_publish`). Every existing backend (Docker, Podman, AppleContainer) declares honest values for all seven flags.

Purpose: Lock in the compile-time exhaustiveness contract (D-02) that this milestone's later phases depend on. After this plan lands, adding any new capability flag forces every backend to declare a value or the build fails.

Output: Modified trait, struct, three runtime const literals, and supporting tests that prove every backend's capability matrix is what we say it is.
</objective>
